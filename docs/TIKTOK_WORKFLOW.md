# TikTok — fluxo do Price Scout

O Price Scout já gera os ativos necessários para um fluxo semi-automático:

- card vertical 1080×1920 em PNG;
- preço antigo e preço atual;
- percentual de desconto;
- economia em reais;
- classificação da oferta;
- loja e avaliação quando informadas;
- legenda pronta;
- hashtags sugeridas.

## Uso atual

1. Gere a promoção no **Promo Studio**.
2. Baixe o card 1080×1920.
3. Copie a legenda e hashtags.
4. Use o card como base para post, slideshow ou vídeo curto no TikTok.

## Automação futura

A publicação automática deve ser implementada somente pela API oficial de Content Posting do TikTok, com aplicativo registrado, autorização da conta e permissões exigidas pela plataforma.

Nenhuma senha do TikTok deve ser salva no Price Scout ou no GitHub.
